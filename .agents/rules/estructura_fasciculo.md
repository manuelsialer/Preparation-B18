# Estructura Estándar de los Fascículos Didácticos

Cada fascículo de la carpeta `Clases/` debe seguir esta estructura obligatoria:

1. **Encabezado y Metadatos:**
   - Materia, Número de Fascículo y Título.
   - Indicador Oficial de PRONABEC / CNEB asociado.
   - Competencia y Capacidades a desarrollar.

2. **Sección Teórica Completa:**
   - Introducción y motivación práctica.
   - Definiciones rigurosas explicadas con lenguaje amigable.
   - Teoremas, demostraciones clave y propiedades.
   - Alertas de errores comunes.

3. **Sección de Ejercicios Resueltos Paso a Paso (10 ejercicios):**
   - Nivel Básico (3 problemas de afianzamiento directo).
   - Nivel Intermedio (4 problemas de aplicación combinada).
   - Nivel Avanzado / Contexto Beca 18 (3 problemas de modelamiento real).

4. **Sección de Práctica Propuesta (Mínimo 45 ejercicios con 5 alternativas A-B-C-D-E):**
   - **Bloque I - Básico (15 ejercicios):** Fijación conceptual y agilidad operativa.
   - **Bloque II - Intermedio (15 ejercicios):** Raciocinio, planteo de problemas y métodos combinados.
   - **Bloque III - Avanzado / Tipo Beca 18 (15 ejercicios):** Problemas extensos de contexto real (comercial, científico, productivo).
   - **Cuadro de Claves de Respuestas:** Tabla con las alternativas correctas de los 45 ejercicios.
   - **Pistas y Guía de Solución:** Breve orientación para los 5 problemas más desafiantes del Bloque III.

5. **Formulario Resumen (Cheat Sheet Matemático en LaTeX):**
   - Prohibido usar cajas de texto plano ASCII (como `┌───┐`).
   - Debe diseñarse íntegramente con **fórmulas en LaTeX**, bloques destacados (`$$...$$`), tablas Markdown limpias y entornos matemáticos ordenados para que renderice con máxima elegancia tipográfica.
   - Síntesis de fórmulas y propiedades esenciales condensadas en un formato visual atractivo.
